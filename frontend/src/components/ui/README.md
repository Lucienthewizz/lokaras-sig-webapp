# UI Components

Folder ini berisi komponen reusable yang tidak terikat fitur tertentu.

- `Button.jsx`: tombol umum dengan variant dasar.
- `Badge.jsx`: label kecil untuk status/kategori.
- `EmptyState.jsx`: tampilan kosong reusable.

Gunakan dari fitur dengan import:

```js
import { Badge, Button, EmptyState } from "../../../components/ui";
```
